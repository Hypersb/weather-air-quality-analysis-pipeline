# Weather & Air Quality Data Pipeline

This project will become an end-to-end data engineering and analytics project using:

- Open-Meteo APIs
- Python
- Pandas
- PostgreSQL
- SQL
- Tableau

## Planned Architecture

```text
Open-Meteo Weather API
            \
             -> Python ETL -> PostgreSQL -> SQL Analysis -> Tableau
            /
Open-Meteo Air Quality API
```
